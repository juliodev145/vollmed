# PRINCIPAIS COMANDOS DO EXPO
1. `npx create-expo-app@latest nomedoprojeto --template blank-typescript` -> Criação do projeto contendo uma base inicial.
2. `npx expo start` -> Inicia o servidor de desenvolvimento.
3. ``npm run reset-project`` -> Limpa os arquivos da apresentação.
